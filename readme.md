### Controls:
- `W`, `S`, `A`, `D`, or arrow keys to move
- `CTRL+F` to toggle fullscreen

### Debug:
Press `L` to toggle "debug mode".

While in "debug mode" press:
- `1`: regular zoom level
- `2`: zoomed out mode to check maps loading
